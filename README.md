# MotoCare

O MotoCare é um aplicativo Android desenvolvido em Kotlin para o gerenciamento de motocicletas, como parte do projeto final da disciplina de Desenvolvimento Mobile II, do curso de Análise e Desenvolvimento de Sistemas da UPF.

## Funcionalidades

O aplicativo permite que o usuário cadastre suas motocicletas e acompanhe informações importantes sobre cada uma delas.

Entre as principais funcionalidades estão:

- Cadastro e gerenciamento de motocicletas.
- Registro de abastecimentos.
- Acompanhamento da quilometragem.
- Histórico de abastecimentos e manutenções.
- Registro de serviços realizados, como troca de óleo e revisões.
- Controle dos gastos com combustível e manutenção.
- Agendamento e acompanhamento de próximas manutenções.

## Como funciona

O usuário realiza o cadastro no aplicativo e adiciona sua motocicleta, informando os dados necessários.

Após o cadastro, é possível registrar abastecimentos, atualizar a quilometragem e adicionar manutenções realizadas. O aplicativo organiza essas informações e permite consultar o histórico e os gastos de cada motocicleta.

Também é possível cadastrar futuras manutenções para acompanhar os serviços que precisam ser realizados.

## Tecnologias utilizadas

- Kotlin
- Android Studio
- XML
- Room e SQLite
